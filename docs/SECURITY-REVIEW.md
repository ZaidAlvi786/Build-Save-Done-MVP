## Dependency disposition

The current lockfile audit identifies four root advisories: braces stack-exhaustion denial of service, node-forge RSA verification, sprintf-js unbounded-precision denial of service, and uuid buffer bounds. The 59 package entries include propagated dependency findings; they are not 59 distinct vulnerabilities. See `DEPENDENCY-AUDIT.json` for ranges, affected paths, advisory URLs and npm fix proposals. Many affected paths are build/test tooling, but that does not eliminate build-chain exposure. Do not assume the shipped runtime is clean without examining its dependency/bundle graph.

`npm audit fix --dry-run --json` fails with ERESOLVE involving Jest 29/30 and jest-expo's watch dependency. No lockfile changes or forced repairs were made. npm proposes major Jest/jest-expo changes and an incompatible RN downgrade for some propagated findings; other roots have no offered fix. Reassess compatible upstream releases, regenerate the audit, rerun Expo compatibility checks, CI and native builds before clearing this blocker. Audit and desktop performance artifacts under dist are local, ignored evidence; the compact advisory record is kept in docs.

## Store/privacy gaps

An in-app delete path does not fulfill the external deletion-link requirement by itself. Publish a functioning privacy policy and deletion-request resource under the owner's identity, configure support details, verify provider data handling and complete Play declarations before beta. No external website/product feature has been built, preserving the MVP's saved-places-only scope.
